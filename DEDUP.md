# Registri Proyek — anti-dobel lintas channel

Template kosong.

Kunci proyek = alamat kontrak, ATAU domain/link resmi, ATAU nama proyek
(dinormalisasi: huruf kecil, tanpa spasi). Sebelum mengerjakan post baru,
cocokkan kuncinya ke daftar ini. Kalau sudah ada — JANGAN kerjakan lagi,
catat sebagai dobel.

Format: `kunci | status | tanggal | catatan`

Status yang dipakai: DONE / CLAIMED / MINTED / GAGAL / SKIPPED / CLOSED /
PENDING / PARTIAL / BLOCKED.

## Sudah dikerjakan / diklaim (jangan sentuh lagi)

- contoh-proyek | DONE | 2026-01-01 | CONTOH FIKTIF — hapus baris ini saat mulai memakai registri: proyek contoh selesai dikerjakan.
